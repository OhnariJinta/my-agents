# Environment Security Policy

## 目的
環境作成時にランサムウェア対策とライセンス統制を標準化する。

## 必須ルール

1. 未検証スクリプトの直接実行を禁止する（署名/ハッシュ確認必須）。
2. 依存はバージョン固定（pin）し、可能な限りハッシュ検証を行う。
3. 90日間クールダウン要件がある仕組み・ツールは標準利用しない。
4. ライセンス条件が厳しい、または不明瞭な依存は標準利用しない。
5. 3, 4 の例外は、実行前に明示的な許可を取得する。
6. 依存追加・環境変更は記録者がログに残す。

## 許可フロー

1. Planner が例外理由を文書化
2. Auditor がリスク評価
3. Orchestrator が承認依頼を発行
4. 許可が得られた場合のみ Executor が実施
